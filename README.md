# Central de Posts · Odontologia

1. `npm install`
2. Crie `.env.local` (veja `.env.example`) com sua MANUS_API_KEY
3. `npm run dev` e abra http://localhost:3000
4. Edite `lib/brand.js` (nome, CRO, cores) e o prompt em `app/api/generate/route.js`

Deploy: GitHub + Vercel, cadastrando MANUS_API_KEY e MANUS_PROFILE em Environment Variables.
